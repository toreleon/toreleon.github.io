Start with a small program

From checkout
to COBOL.

Clone the project, install its pinned Rust toolchain, and run the included fixed-format HELLO fixture.

The repository pins Rust 1.98.0. The standalone server is a development composition; consult the operations runbook before starting it.

Operations runbook ↗
QUICK START / SHELL
git clone https://github.com/toreleon/mainframe-env.git
cd mainframe-env

# Install the toolchain pinned in rust-toolchain.toml
rustup toolchain install 1.98.0

# Run the included fixed-format COBOL fixture
cargo run --quiet -p mainframe-env-cli \
  --bin mainframe-env -- \
  run conformance/0.1/fixtures/cobol/HELLO.cbl \
  --format fixed

# Clear local build artifacts when finished
cargo clean
